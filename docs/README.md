## 核心业务理念

HealthPilot AI 采用统一身心健康管理模式。

系统综合考虑身体健康、心理健康、饮食、睡眠作息和长期健康目标，形成一个连续的管理过程：

1. 建立统一健康画像
2. 制定综合健康计划
3. 每日执行、打卡与反馈
4. 周度、月度复盘
5. 根据反馈调整下一周期计划
