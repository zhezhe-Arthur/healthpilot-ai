# HealthPilot Agent

## 模块简介

HealthPilot AI 的智能体服务，使用 Python、LangChain 和 LangGraph 构建。

负责综合分析用户身体状况、心理状态、生活习惯及长期目标，持续生成健康计划、提供支持性的心理健康建议，并根据执行记录进行复盘和重新规划。

## 技术栈

- Python
- LangChain
- LangGraph
- DeepSeek API / Ollama
- Pydantic
- FastAPI
- RAG 向量知识检索

## 核心功能

### 1. 综合健康计划生成
- 获取统一健康画像
- 分析健康目标与限制
- 生成日、周、月健康计划
- 综合考虑运动、饮食、睡眠、心理状态及户外活动

### 2. 长期身心健康管理
- 读取授权的历史健康记录
- 识别生活方式与情绪变化趋势
- 提供非诊断性的心理支持及压力管理建议
- 根据用户偏好调整计划难度

### 3. 健康计划复盘
- 获取上一周期计划
- 分析任务完成情况
- 总结用户反馈与执行困难
- 生成下一周期计划草稿

### 4. Agent 工作流
- Tool Calling
- State 状态管理
- Checkpointer 状态恢复
- 长期记忆
- Human-in-the-loop
- Guardrails
- 结构化输出

### 5. 健康知识检索
- RAG 健康知识库
- 可信来源检索
- 建议依据引用及校验

## 核心流程

统一健康画像 → 综合计划 → 用户确认 → 每日执行与交流 → 周期复盘 → 下一轮计划

## 安全原则

本项目提供健康促进和生活方式管理支持，不替代医生或心理健康专业人员，不提供疾病诊断或治疗决策。

Agent 通过受保护的 Java 业务接口读取授权数据，不直接访问业务数据库。
