# 2 型糖尿病：监测与已有复查安排

D2 的 Check your blood glucose levels 支持与医疗团队确定监测方式、频率及个人目标，并记录结果与相关情境。见 [sources.md](sources.md)。

项目记录设计：

- 保留日期、时间、原数值、原单位及用户提供的空腹/餐后/随机情境；无法确认时标未知。
- 血糖与 HbA1c 分开记录；不混合单位比较，不自行补算、诊断或判定控制程度。
- 用户明确提供的饮食、活动或不适可作为观察记录，不推断因果关系。
- 检查结果与复查安排分别保存来源；日期未知时列“需确认”，不自动套用年度、季度或每日周期。
- 只向 weekly_planning 传递本周相关的已有事项及限制，缺失反馈不等于按时检测或数值正常。
- Java 执行提醒与记录持久化，模型不声称已保存或已提醒。

本包不提供低血糖/高血糖的药物、剂量、处置算法或数值报警规则。严重不适沿用 safety.md 的及时求助边界。
