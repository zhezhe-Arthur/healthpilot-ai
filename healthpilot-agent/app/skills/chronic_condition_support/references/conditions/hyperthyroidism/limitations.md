# 甲状腺功能亢进：适用限制

适用：已确诊非孕成年人的一般记录与就诊沟通。

不覆盖：儿童、孕产期、急性严重不适、放射性碘或术后专属处置。特殊人群仍可忠实整理已有安排，不能新增专属方案。

不把非主动体重下降当作减脂成功，不在有不适或限制不明时自动加大运动。不得自行补碘、禁碘或开营养剂量；不改药。当前胸痛、晕厥、严重气促或意识异常按 safety.md 优先求助。

本包不诊断、不用药、不估计分期/预后，不设个人数值目标或固定检查周期。单来源或旧资料不得被解释为最新临床指南；来源冲突或个人条件未知时暂停受影响的新增建议。

这次专科扩展不解除项目安全边界。已有记录不等于当前病情；严重当前不适按 safety.md 优先联系当地医疗/急救服务。没有构建完整急症分诊、临床监护或治疗推荐功能。
