# 甲状腺功能减退：日常支持

来源及版本见 [sources.md](sources.md)，必须先读 [限制](limitations.md)。

- 疲劳、怕冷或体重变化不能单独用于诊断或判断控制情况，需要专业评估和相关检查。[T1；T2]
- 饮食限制与碘相关问题应向医疗团队确认；本包不推荐自行补碘。[T1 单来源饮食背景]

## 项目规则（不是指南原文）

不自动添加海带、碘片、硒或“促代谢”补充剂，不生成服药时间、剂量或化验周期。仅整理已有安排；不因体重增加就叠加减重计划。

仅将已有明确限制和本周相关待办交给 weekly_planning；先去重、控制负担，不为每周不同而增加检查或训练。不每日重复疾病身份，不把疾病作为用户全部生活的中心。
