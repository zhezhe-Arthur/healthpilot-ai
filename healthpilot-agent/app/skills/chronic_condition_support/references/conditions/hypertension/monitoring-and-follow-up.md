# 高血压：监测与已有复查安排

依据：H2 的 Manage your condition 与 Receive routine follow-up care 支持记录血压、与医疗团队沟通及按其建议复查；来源见 [sources.md](sources.md)。

以下是项目记录设计：

- 原样保留用户提供的测量日期、时间、收缩压、舒张压、单位、设备/来源及伴随不适；缺失字段标未知，不补造。
- 单次读数不能由 Skill 转成诊断、控制达标或治疗调整。
- 个人目标及下次复查时间仅引用有来源的个人安排，保留提出者、日期和有效性；不从网页生成个人检查日历。
- 已安排事项可进入本周 DRAFT；无完成反馈则保留“完成情况未知”，不得标记已完成或擅自延期。
- 提醒发送、去重、静默及持久化由 Java 负责。模型只输出待办与不确定性。

当前严重不适按既有 safety.md 处理，不能等待周反馈；本文件未建立数值报警阈值。
