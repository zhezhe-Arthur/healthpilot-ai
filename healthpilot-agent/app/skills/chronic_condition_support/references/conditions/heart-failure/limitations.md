# 心力衰竭：适用限制

限成年人的已有信息与常规安排整理；心衰类型、射血分数或分级由医疗文书提供，模型不推断。急性失代偿、近期住院和器械/移植相关管理不新增个人方案。

## 当前异常与求助

新发或加重的气促、突然体重增加或水肿应及时联系医疗团队，不等待周反馈。[H1；H2] 当前严重呼吸困难、意识异常等按 safety.md 联系当地急救服务；无需先获得称重或血氧数据。

以上仅为非穷尽求助提示，不是完整分诊算法或诊断规则。数值看似正常不能抵消当前明显不适。按当地服务求助，不直接复制美国或英国急救号码；不能让等待后台通知替代求助。

## 不采用的内容

不统一限水、限盐、设体重增幅报警值或调整利尿剂；不因其他病种建议补水而覆盖已有液体限制，也不把气促归结为焦虑。

不诊断、不用药、不推导个人目标或统一检查周期。外国公共健康教育不等于中国个体诊疗标准；不确定或冲突时暂停受影响的新增建议，保留现有信息并形成专业咨询问题。本包未验证模型安全行为或临床效果。
