# 冠心病：日常注意

证据 ID、版本与章节见 [sources.md](sources.md)，使用前读 [limitations.md](limitations.md)。

- 心脏康复由专业团队组织，帮助适宜人群恢复活动；不意味着所有冠心病用户都适用同一课程。[C1；C2]
- 复查和新发症状需与医疗团队沟通，个人活动限制应保留。[C1；C2 支持专业恢复计划，具体复查要求来自 C1]

## 项目应用规则

只将已有个人安排和适用的一般注意事项交给相关 Skill；专业康复任务优先保留，普通运动任务不得机械叠加。周计划去重、控制负担，不为了“每周不同”而自行增加强度。

不每天重复病名或疾病身份。没有每日产品打卡不代表应降低医生要求的监测频率；已有频率保留，由 Java 按授权处理提醒，不由模型循环通知。
