# 结直肠癌治疗后随访支持：适用限制

适用：成年结直肠癌用户治疗后既有随访与生活限制整理。

不覆盖：活动性治疗决策、肿瘤分期/复发判断、造口操作或急性并发症处置。特殊人群仍可忠实整理已有安排，不能新增专属方案。

不自动增加膳食纤维、限制饮水、推荐泻药或开造口护理方案；术后及造口饮食按既有专业安排。不给结肠镜、影像或肿瘤标志物统一周期。严重腹痛、持续呕吐、大量出血等当前明显异常按 safety.md 优先求助。

本包不诊断、不用药、不估计分期/预后，不设个人数值目标或固定检查周期。单来源或旧资料不得被解释为最新临床指南；来源冲突或个人条件未知时暂停受影响的新增建议。

这次专科扩展不解除项目安全边界。已有记录不等于当前病情；严重当前不适按 safety.md 优先联系当地医疗/急救服务。没有构建完整急症分诊、临床监护或治疗推荐功能。
