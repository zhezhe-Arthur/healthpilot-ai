# 慢性乙型肝炎：适用限制

适用：已有专业诊断成人的记录、随诊沟通与有限健康教育。

不覆盖：急性乙肝、未明确急慢性、孕产期母婴阻断、肝硬化失代偿、肝癌及移植专属方案。特殊人群仍可忠实整理已有安排，不能新增专属方案。

不自动制定抗病毒方案、肝癌监测周期、家庭成员筛查或疫苗日程；可整理专业咨询问题。乙肝是可长期存在的感染，不能沿用“慢性病均不传染”的说法；不主动向他人披露疾病信息。

本包不诊断、不用药、不估计分期/预后，不设个人数值目标或固定检查周期。单来源或旧资料不得被解释为最新临床指南；来源冲突或个人条件未知时暂停受影响的新增建议。

这次专科扩展不解除项目安全边界。已有记录不等于当前病情；严重当前不适按 safety.md 优先联系当地医疗/急救服务。没有构建完整急症分诊、临床监护或治疗推荐功能。
