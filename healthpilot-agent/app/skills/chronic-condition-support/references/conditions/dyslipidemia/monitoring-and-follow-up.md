# 血脂异常：记录与已有复查安排

医学背景和证据边界见 [sources.md](sources.md)。以下字段及流程为项目设计，不是指南要求的检查清单。

分别保留总胆固醇、LDL-C、HDL-C、甘油三酯的原始名称、数值、单位、采样时间及报告注明的空腹状态。未知不补；不同指标或单位不混用。既有目标注明来源，不运行风险评分，不自动判定达标。

- 每条记录区分医疗文书、用户转述、设备或个人观察，保留时间与来源；不凭数值猜测诊断或原因。
- 仅整理医生已有的检查/复查安排，保留项目、日期、提出者和适用条件。没有日期则标待确认，不从网页推算周期。
- 下周缺失反馈时保留“完成情况未知”；已知异常未获后续信息时仍为未解决，不判为稳定或自行延期。
- weekly-planning 只将本周相关事项排入 DRAFT 并控制负担；Java 负责保存、定时触发、通知和去重，模型不声称已执行。
- 当前严重不适沿用 safety.md 的及时求助边界，不等周反馈。本包不提供完整急症分诊或数值警报规则。
