# 卒中后管理：适用限制

限成年卒中后既有康复安排的整理与支持，不覆盖急性卒中治疗，也不自动等同于短暂性脑缺血发作管理。不推断缺血/出血类型，不自行制定防复发治疗或康复动作。

## 当前异常与求助

突然新发面部歪斜、单侧肢体无力或言语异常等，应立即联系当地急救服务；即使症状短暂消失也不能等下次反馈，不自行驾车。[S3；S1 支持再发迹象立即求助] 例子不穷尽，不要求同时出现。

以上仅为非穷尽求助提示，不是完整分诊算法或诊断规则。数值看似正常不能抵消当前明显不适。按当地服务求助，不直接复制美国或英国急救号码；不能让等待后台通知替代求助。

## 不采用的内容

不自行更改食物质地、液体稠度或开展吞咽训练；新发呛咳/吞咽困难交专业评估。不得照搬普通步数或平衡训练，不自动许可以前的工作、驾驶或独立活动。

不诊断、不用药、不推导个人目标或统一检查周期。外国公共健康教育不等于中国个体诊疗标准；不确定或冲突时暂停受影响的新增建议，保留现有信息并形成专业咨询问题。本包未验证模型安全行为或临床效果。
