# 肥胖症：适用限制

限成年、非孕且适合一般生活管理的用户；儿童、孕产期、进食障碍风险、术后及复杂专科情况不生成减重方案。不能只凭外观或单一 BMI 诊断，不套用美国 BMI 分类作为中国诊断。

不叠加多个病种的热量缺口，不默认节食越多越好；肾病、骨质疏松和关节限制需先协调。避免羞辱性措辞或每日重复体重标签。

本包不诊断、不用药、不制定治疗/营养补充剂剂量，不设置个人数值目标或固定检查周期。只允许 sources.md 中明确支持的一般事实；不能用模型记忆补齐专科知识。

外国健康教育资料不是中国个人诊疗标准；存在来源差异、旧版本或不确定性时先保留未知。与个人医嘱冲突时暂停受影响的新增建议并整理咨询问题，不自行选择“更严格”的规则。

无反馈不证明病情稳定或遵从安排。未完成模型行为验收及临床效果验证。
