# 乳腺癌治疗后随访支持：适用限制

适用：成年乳腺癌用户进入专业团队安排的治疗后随访阶段，仅整理既有安排。

不覆盖：活动性治疗决策、疑似肿瘤诊断、分期/复发判断、转移或急性并发症处置。特殊人群仍可忠实整理已有安排，不能新增专属方案。

不自行安排乳腺影像/肿瘤标志物周期、上肢康复或营养处方；不判定治愈、复发概率或生存期。NHS 页面针对女性/有乳房人群，其他人群仅沿用通用既有信息整理，不外推专属建议。

本包不诊断、不用药、不估计分期/预后，不设个人数值目标或固定检查周期。单来源或旧资料不得被解释为最新临床指南；来源冲突或个人条件未知时暂停受影响的新增建议。

这次专科扩展不解除项目安全边界。已有记录不等于当前病情；严重当前不适按 safety.md 优先联系当地医疗/急救服务。没有构建完整急症分诊、临床监护或治疗推荐功能。
