# 高血压：日常注意

证据 ID 与版本见 [sources.md](sources.md)，边界见 [limitations.md](limitations.md)。

- 健康饮食、减少盐摄入、适当活动及避免烟草是一般生活管理方向。[H1 Treatment；H2 Manage your condition]
- 高血压可能没有明显症状；感觉正常不能替代既有监测与随诊。[H1 Overview、Symptoms；H2 Receive routine follow-up care]

项目使用规则：只在用户希望安排相关行动时，将上述方向交给 nutrition/exercise；运动量和饮食限制服从已有个人安排。合并肾病时，不自动添加高钾饮食、含钾代盐或饮水量建议。后者是本项目的保守限制，不是这两页给出的统一处方。

周计划可写“按已有安排整理本周血压记录”；无需每天重复病名或要求每日打卡。
