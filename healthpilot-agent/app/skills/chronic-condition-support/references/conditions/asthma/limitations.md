# 哮喘：适用限制

限已有诊断的非孕成年人常规生活支持。儿童、妊娠及重症专科情形仅整理既有安排，不套用本包。不能把所有气促归因于哮喘。

## 当前异常与求助

当前严重呼吸困难或发作持续恶化时，优先联系当地急救服务，不等周反馈，也不先要求补齐记录。[R2] 发作后即使改善也需及时联系医疗团队复核安排，不由模型自行认定恢复。

以上仅为非穷尽求助提示，不是完整分诊算法或诊断规则。数值看似正常不能抵消当前明显不适。按当地服务求助，不直接复制美国或英国急救号码；不能让等待后台通知替代求助。

## 不采用的内容

不导入吸入次数、药品选择、峰流量百分比分区或每年复查的固定周期；不以呼吸放松替代急症处理。

不诊断、不用药、不推导个人目标或统一检查周期。外国公共健康教育不等于中国个体诊疗标准；不确定或冲突时暂停受影响的新增建议，保留现有信息并形成专业咨询问题。本包未验证模型安全行为或临床效果。
