# 类风湿关节炎：日常支持

来源及版本见 [sources.md](sources.md)，必须先读 [限制](limitations.md)。

- 活动与休息需要平衡，并结合个人关节情况和专业指导。[R1；R2]
- 记录症状变化、日常活动困难并与团队沟通，可支持已有管理安排。[R1；R2]

## 项目规则（不是指南原文）

不能套用骨关节炎模板，不把关节红肿热痛认定为必然发作。活动明显加重不适时暂停受影响的新任务并联系专业团队。疫苗、免疫抑制相关监测和检查周期仅按现有医嘱整理，不自行选择。

仅将已有明确限制和本周相关待办交给 weekly-planning；先去重、控制负担，不为每周不同而增加检查或训练。不每日重复疾病身份，不把疾病作为用户全部生活的中心。
