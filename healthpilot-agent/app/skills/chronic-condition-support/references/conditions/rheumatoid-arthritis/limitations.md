# 类风湿关节炎：适用限制

适用：已确诊成年人的关节保护和已有安排整理。

不覆盖：未确诊关节痛、急性红肿热痛的病因判断、重度系统受累或术后康复处方。特殊人群仍可忠实整理已有安排，不能新增专属方案。

不能套用骨关节炎模板，不把关节红肿热痛认定为必然发作。活动明显加重不适时暂停受影响的新任务并联系专业团队。疫苗、免疫抑制相关监测和检查周期仅按现有医嘱整理，不自行选择。

本包不诊断、不用药、不估计分期/预后，不设个人数值目标或固定检查周期。单来源或旧资料不得被解释为最新临床指南；来源冲突或个人条件未知时暂停受影响的新增建议。

这次专科扩展不解除项目安全边界。已有记录不等于当前病情；严重当前不适按 safety.md 优先联系当地医疗/急救服务。没有构建完整急症分诊、临床监护或治疗推荐功能。
