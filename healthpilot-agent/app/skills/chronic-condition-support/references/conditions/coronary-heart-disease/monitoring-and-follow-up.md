# 冠心病：记录与已有复查安排

以下为项目记录设计，医学背景见 [sources.md](sources.md)，不是官方检查清单。

保留用户转述的诊断、住院/手术/介入日期及出院限制，不能由“装过支架”推断已无风险。胸部不适记录区分过去与当前，记录开始时间、持续情况、活动情境与伴随症状，不判断心绞痛分型或病因。仅整理已确定的康复与复查事项。

- 复查项目、频率及日期仅来自有效个人安排；未知标待确认，不自行套用指南或网页周期。
- 没有反馈不等于未监测、未完成或稳定；已有异常没有后续信息时，记录“后续情况未知”，不宣称持续恶化或已恢复。
- 周计划只整合本周相关待办并生成 DRAFT，个人医嘱频率不能因产品每周反馈而改变。
- Java 负责保存、定时触发、通知、去重及暂停。模型只输出信息，不声称已保存、预约或通知。
- 当前急性异常先按 [限制与求助边界](limitations.md)处理；不等待复查日期或下一次模型调用。
