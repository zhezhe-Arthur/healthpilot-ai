# 慢性乙型肝炎：日常支持

来源及版本见 [sources.md](sources.md)，必须先读 [限制](limitations.md)。

- 慢性乙肝需要专业随诊与肝脏情况监测，症状不能代替检查。[B1；B2]
- CDC 明确说明不会通过共同使用餐具或拥抱传播；避免不必要隔离与污名化。[B2 单来源事实]
- 保健品、草药等应先向专业人员咨询，不将其当作保肝治疗。[B2]

## 项目规则（不是指南原文）

不自动制定抗病毒方案、肝癌监测周期、家庭成员筛查或疫苗日程；可整理专业咨询问题。乙肝是可长期存在的感染，不能沿用“慢性病均不传染”的说法；不主动向他人披露疾病信息。

仅将已有明确限制和本周相关待办交给 weekly_planning；先去重、控制负担，不为每周不同而增加检查或训练。不每日重复疾病身份，不把疾病作为用户全部生活的中心。
