# 运动安全规则

版本：草稿 v0.1
资料核对日期：2026-11-26

本文件定义 HealthPilot 的保守分流策略。
它不是诊断工具、临床分级系统或运动许可证明。
下列症状示例不是穷尽清单。

## 一、分流结果

使用四种内部结果：

- STOP：停止当前运动，优先处理异常症状。
- REVIEW：暂停新的个体化训练安排，先澄清或接受专业评估。
- NEEDS_INFO：缺少足以影响安全或适用范围的信息。
- PROCEED：可以继续一般运动规划，但不表示已排除风险。

已知急性危险信号优先于资料缺失。
不要为了完成信息收集而延迟 STOP 提示。

## 二、STOP：当前异常症状

用户报告以下情况时，不继续安排训练或建议带症状坚持：

- 当前突发且持续的胸痛或胸部压迫感。
- 胸痛伴出汗、恶心、头晕或呼吸困难，
  或疼痛向手臂、颈部、下颌、背部等扩散。
- 当前严重或异常呼吸困难。
- 运动中晕厥、接近晕厥，或明显急性严重不适。

处理：
1. 建议立即停止运动。
2. 当前症状严重、持续或疑似紧急情况时，
   建议联系当地急救服务，不自行驾车就医。
3. 不诊断为心脏病、焦虑、低血糖或其他具体原因。
4. 不提供“先喝水、休息几分钟再继续”的替代训练方案。
5. 不生成占位七天训练计划。

急救信息：
- 地区未知时说“当地急救电话”，不猜测号码。
- 地区已明确且号码可靠时，才给出适用号码。
- NHS 来源中的英国号码不能默认用于中国用户。

胸痛相关依据见本文件末尾 S1。
其他急性严重症状采用项目保守停止策略，
不声称这是一套经过验证的完整分诊算法。

## 三、REVIEW：先澄清或接受专业评估

以下情况不直接增加负荷或生成未经限制的训练：

- 持续、加重或影响活动的疼痛。
- 近期手术、伤病或急性疾病，恢复状态不明。
- 既往运动时出现胸痛、晕厥等异常情况，
  尚未明确接受评估或获得相关建议。
- 原因不明的运动能力明显下降。
- 已有专业人员要求限制运动，但具体限制不清楚。
- 现有症状或限制超出本 Skill 能够处理的范围。

处理：
- 明确哪些信息需要补充。
- 建议适当的专业评估，不断言具体病因。
- 已有专业建议时，在其明确范围内组织信息，
  不修改治疗、康复方案或用药。
- 不默认所有活动都必须停止，也不擅自推荐替代运动；
  依据当前限制判断是否能给出一般信息。
- 无法判断是否急性严重时，优先询问当前症状，
  并在存在紧急迹象时升级为 STOP。

## 四、NEEDS_INFO：不能把未知当作正常

制定个体化计划前，应具有足够信息确认：
- 用户属于何种年龄范围。
- 是否存在当前异常症状或明确运动限制。
- 当前活动基础和可耐受程度。

缺失时：
- 说明缺失项，不虚构“用户无基础疾病”。
- 提出简短、相关的问题。
- 不强制收集完整病历或所有健康指标。
- 不要求所有无症状成年人先体检才允许一般活动。
- 仅缺少活动偏好等非安全信息时，可继续给出标注假设的选项。

## 五、人群范围

### 一般成人

在未报告需要停止或评估的问题、关键信息充分时，
可生成一般活动建议。

PROCEED 仅表示“根据现有信息可以继续规划”，
不能表述为“运动绝对安全”。

### 老年人

年龄本身不是停止活动的理由。

关注：
- 目前功能与活动基础。
- 跌倒史、平衡困难。
- 环境支持和已知限制。

缺乏这些信息时，不安排无支撑的高难度平衡动作。
不因年龄直接假定衰弱，也不忽略实际功能限制。

### 未成年人、孕产妇及复杂情况

本 Skill 默认成人流程不能直接覆盖：
- 未成年人。
- 妊娠及产后阶段的个体化训练。
- 复杂慢病、明显功能障碍。
- 专项康复或竞技训练。

处理：
- 说明范围限制。
- 可解释相应指南的一般原则。
- 未取得适用资料与充分个体信息时，
  不输出成人模板替代专门方案。

慢病或残障不等于禁止运动；
但本 Skill 不能凭一个病名推导出安全剂量。

## 六、运动安排中的限制

- 不把疼痛当作必须忍受的训练效果。
- 不默认使用HIIT、冲刺、最大重量或力竭训练。
- 不用估计BMI、体重变化决定用户能否运动。
- 不凭症状调整药物、补充剂或治疗计划。
- 不保证减重、降压、降糖或疾病改善幅度。
- 不把主观疲劳评分单独当作诊断或急救阈值。
- 不把普通肌肉酸痛自动诊断为损伤；
  无法区分时先澄清持续时间、变化和功能影响。

## 七、向整合流程传递限制

输出需要处理的限制及理由，不只输出状态标签。

例如：
- “近期伤病限制未明确，本次不生成负重安排。”
- “当前存在严重异常症状，暂停运动规划并建议及时求助。”
- “当前资料不足，需确认活动基础与运动限制。”

weekly-planning 不应为了凑齐七天而填补被阻止的训练。
任何新建议仍需走 Java 管理的草稿和用户确认流程。
