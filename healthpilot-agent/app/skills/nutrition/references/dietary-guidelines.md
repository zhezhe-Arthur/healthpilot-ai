# 饮食依据与口径

版本：草稿v0.1
核对日期：2026-11-26

本文为精简综合笔记，不是官方译文或完整指南。
默认用于一般成人健康教育，不能直接覆盖特殊人群。

## 一、中国居民膳食指南2022

来源N1：平衡膳食八准则。

主要方向：
- 食物多样，合理搭配。
- 吃动平衡。
- 重视蔬果、奶类、全谷和大豆。
- 适量选择鱼、禽、蛋和瘦肉。
- 控制盐、油、添加糖及酒精摄入。
- 规律进餐、适量饮水。
- 注意食品标签、烹饪卫生和食物浪费。

供一般成人解释时使用的部分数值：
- 新鲜蔬菜每日不少于300克。
- 新鲜水果每日200–350克。
- 奶制品相当于每日300毫升以上液态奶。
- 成人每日盐不超过5克。
- 添加糖每日不超过50克，最好低于25克。
- 温和气候、低身体活动水平下，
  成年男性每日饮水1700毫升，女性1500毫升。

这些数值不自动成为个人必须完成的任务。
已有饮水或其他营养限制时，不能直接套用。

## 二、WHO健康饮食

来源N2：Healthy diet。

主要原则：
充足、平衡、适量、多样，同时关注食品安全。

成人一般参考：
- 每日蔬果至少400克。
- 每日天然膳食纤维至少25克。
- 游离糖低于总能量10%，进一步降至5%或以下
  可能带来额外获益。
- 成人每日盐少于5克。
- 优先不饱和脂肪，限制饱和及反式脂肪。

不能将成人数字直接用于儿童。
不能在没有能量需要估计的情况下，
将能量百分比硬算成个人每日糖摄入克数。

## 三、不同来源不能机械合并

- 中国指南分别列蔬菜、水果，
  WHO列蔬果合计；不要把两组目标相加。
- 添加糖与游离糖不是同一概念。
- 游离糖还涉及蜂蜜、糖浆及果汁等来源。
- 饮水量不等于来自全部食物和饮料的总水摄入。
- 烹调油量不等于全天总脂肪量。
- 盐与钠不是相同单位；盐目标不能只计算做饭时加的盐。

向中国用户解释时，可以优先使用中国指南框架，
同时保留其他来源的定义差异。

## 四、份量和数据表达

以下为项目规则：

- 精确克数应标明食品状态和计量口径。
- 不能把生米和熟饭视为相同重量的营养输入。
- 不能把“每份”默认成“每100克”。
- 不知道食谱、用油量和份量时，
  不给出看似精确的热量总数。
- 家庭共同用餐不能把全部用油、盐算给一个人。
- 食物替换可以按方便程度和食物类别提出，
  未核算时不能保证热量或营养素完全等价。

## 六、未获支持的推导

本文件不支持：
- 所有人每天都需要相同热量。
- 所有人需要1.6–2.2克/公斤蛋白质。
- 所有人应饮水2.5–3.5升。
- 某种餐单能治疗慢性病。
- 每周必须减重或持续减少食量。
- 食品价格高、标注“天然”就一定更健康。

这些内容不能由模型自行补进项目规则。
