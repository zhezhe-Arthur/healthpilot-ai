# HealthPilot Web

## 模块简介

HealthPilot AI 的 Web 用户端。

提供统一的身心健康管理界面，让用户管理健康资料、查看综合计划、完成每日打卡、与 AI 交流及查看长期健康变化。

## 技术栈

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- TanStack Query
- Zustand
- ECharts

## 主要页面

### 1. 用户登录与健康档案
- 注册、登录
- 首次健康信息录入
- 长期健康目标设置
- 健康资料及偏好修改

### 2. 综合健康首页
- 今日健康状态
- 当前计划及任务完成情况
- 健康趋势摘要
- AI 健康建议

### 3. 健康计划
- 每日任务安排
- 每周、每月计划
- 任务打卡
- 计划修改与确认

### 4. AI 健康伙伴
- 流式 AI 对话
- 健康问题交流
- 心理健康支持
- 计划调整建议

### 5. 健康复盘
- 每周和每月复盘
- 历史计划对比
- 情绪、睡眠、活动等趋势图
- 下一周期综合计划

## 设计原则

用户端以统一健康计划为中心，不将身体、心理、饮食和睡眠拆成相互独立的管理系统。

优先实现桌面及移动浏览器兼容，后期可扩展 React Native 客户端。
