# HealthPilot Server

## 模块简介

HealthPilot AI 的核心业务后端，使用 Java Spring Boot 开发。

负责用户管理、统一健康画像、综合健康计划、每日打卡、周期复盘、数据持久化，以及与 Python Agent 服务通信。

## 技术栈

- Java 17
- Spring Boot 3.5.x
- Spring Security + JWT
- Spring Data JPA
- MySQL 8
- Maven
- Flyway

## 主要功能

### 1. 用户管理
- 用户注册与登录
- JWT 身份认证
- 用户信息及隐私授权管理

### 2. 统一健康画像
- 个人基本健康信息
- 身体健康与生活习惯
- 心理状态和压力记录
- 饮食、睡眠、运动偏好
- 长期健康目标及健康限制

### 3. 综合健康计划
- 每日、每周、每月计划管理
- 任务创建、查询与打卡
- 计划确认、修改及版本记录

### 4. 健康复盘
- 历史执行数据统计
- 周度和月度健康复盘保存
- 下一周期计划管理

### 5. Agent 服务集成
- 调用 Python Agent 服务
- 提供受保护的内部业务接口
- 校验和保存 Agent 生成的计划草稿

## 架构原则

Java 是业务数据的权威管理入口。Agent 不直接修改业务数据库，重要计划变更需通过校验及用户确认。
